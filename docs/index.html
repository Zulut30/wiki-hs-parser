Safe database export

`wiki_hs_export.py` is made for your site backend: it builds the Cargo lookup index, deduplicates wiki pages, caches full parser results, then writes JSONL and optional SQLite without hammering wiki.gg.

Open script 
python wiki_hs_export.py ^
  --scope bg-hero ^
  --output-jsonl out/export/bg-heroes.jsonl ^
  --output-sqlite out/export/bg-heroes.sqlite ^
  --cache-dir out/export-cache ^
  --delay-seconds 1.2 ^
  --jitter-seconds 0.4
Fast lookup firstUses `Special:RunQuery/Card`, `BG/Minion`, and `BG/Hero` through Cargo API batches.
Polite fetchesOne request per unique page, with cache, retry, backoff, delay, and jitter.
DB readyStores page payloads plus lookup rows keyed by `scope`, `card_id`, and `dbf_id`.
Safe testingUse `--max-pages 10` or `--index-only` before a full export.

Patch changes

The parser keeps the patch heading, patch page URL, date, and every listed change item.

  1. 2026-03-10 Patch 35.0.0.237510

    Removed golden card unlock requirement.

  2. 2024-10-29 Patch 31.0.0.210009

    Banned from card generation unless the deck started with C'Thun or a related card.

  3. 2024-03-11 Patch 29.0.0.195635

    No longer globally banned from Arena drafting.

  4. 2023-08-22 Patch 27.2.0.183876

    Cost changed to 8, C'Thun buffs became permanent, and Signature version was added.

  5. 2016-06-01 Patch 5.0.0.13030

    Bug fix for Redemption bringing C'Thun back with full buffed health.

  6. 2016-04-24 Patch 5.0.0.12574

    Added.
